# 简谱（数字谱）识读与转写规则

从扫描/拍照简谱提取旋律时的记谱法规则与实操经验。目标：音高、节奏**逐小节**确定，不留猜测。

## 记号速查（以 4/4、L:1/8 对应）

| 简谱记号 | 时值 | ABC (L:1/8) |
|---|---|---|
| `5` 无减时线 | 四分音符 | `A2` |
| `5̲` 一条减时线 | 八分音符 | `A` |
| `5̲̲` 两条减时线 | 十六分音符 | `A/` |
| `5̲̲̲` 三条减时线 | 三十二分音符 | `A//` |
| `5·` 附点 | 时值 ×1.5 | `A3` / `A3/` |
| `5 -` | 每 `-` 加一个四分音符 | `A4`（=2+2） |
| `0` | 休止符，时值线规则同音符 | `z2` / `z` / `z/` |
| 数字下有点 `5̣` | 低八度 | `A,` |
| 数字上有点 `5̇` | 高八度 | `a` |
| 小数字（上标） | 装饰音（倚音），零时值 | `{...}` |
| `⌒` 连音符 | 同音=延音线，异音=圆周线 | 同音用 `-` |
| `𝄽` / 波浪线 | 波音 | `!mordent!` |
| `𝄐` | 延长记号 | `!fermata!` 或 `H` |
| `1.` / `2.` 房子 | 第一/第二结尾 | `[1` / `[2` |
| `( ... )` | 器乐间奏/尾奏段落 | 照样转写，可加注释 |

## 识读流程

1. **先定系统行带**：把原图按系统（行）裁开，每行再裁成 2–4 段放大图。把每段的坐标记录下来，便于回头复查。
2. **逐行精读，逐小节写下"简谱记号 → ABC"**，当场算每小节合计拍数，必须等于拍号。
3. **拿不准的点立刻回到原图**：从**未缩放的原始像素**重新裁切（PIL `Image.NEAREST` 4 倍放大）。
   - 经过 LANCZOS 等平滑放大的图会**伪造或吞掉附点**——本流程踩过：一个"附点"被放大算法抹掉，导致整小节差半拍。
4. **用拍数反推消歧**（最可靠的判据）：
   - 附点 `·`（时值×1.5，在数字右侧）与低音点（数字下方）在小图上极易混淆 → 两种读法各算一遍小节总长，取等于拍号的那个。
   - 阶梯形减时线（一条线跨两个音、第二条线只跨后一个）= 前八分后十六分；两条线跨三个音且下线只跨后两个 = 八/十六/十六。
   - 若所有音符线数确定仍凑不满拍号，优先怀疑某个"裸数字"其实带附点、或某个 `-` 增时线被漏看。
5. **连音线判断**：跨过小节线的同音弧线，结合歌词断句判断是延音线（tie，同音节延长）还是圆周线（slur，跨字）——看弧线两端音符是否同音、歌词是否换字。
6. **歌词对齐辅助定位**：一字多音处（连音/拖腔）用来确认音符分组归属；器乐段落无歌词，按小节线独立核算。
7. **常见变拍/结构**：弱起小节（正歌 `2 3` 两个八分补足前奏的 3 拍不完全小节）、中段 `2/4` 插入小节、间奏后的 `‖:` `:‖` 反复与 `1.` `2.` 房子、rit. 后"原速"标记——全部照原样保留。

## 高发错误清单（按出现频率）

1. **十六分写成三十二分**（`A/` 误为 `A//`）：小节普遍短缺 1/4–1/2 拍，是谱面"看着挤、拍子对不上"的头号原因。
2. 附点丢失或附点与低音点混淆。
3. 八度点（高/低音点）遗漏，尤其是减时线下方的低音点。
4. 增时线 `-` 漏看（`3 - -` = 6 拍，不是 2 拍）。
5. 弱起小节当作完整小节，或变拍小节（如插入的 2/4）按原拍号硬塞。
6. 间奏器乐曲句的音遗漏（无歌词提示，容易整组丢失）。
